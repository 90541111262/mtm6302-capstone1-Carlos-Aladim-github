Overview
This project is part of the Capstone course and involves creating a website for NASA using HTML, CSS, and JavaScript. The site includes three main pages: HOME, ABOUT, and CONTACT.

Project Details

Files Included:
index.html: Home page of the NASA website.
about.html: About page detailing information about NASA.
contact.html: Contact page with a form for user inquiries.
css/styles.css: CSS file for styling the entire website.
images/: Directory containing all images used in the website.
js/script.js: JavaScript file for interactive elements.

Usage
To view the website:

Clone the repository.
Open index.html in your web browser.
